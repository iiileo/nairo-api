常见问题

上线前后最常问的几件事。

这是官方支付接口吗？

不是。Nairo 基于个人微信 / 支付宝收款码与设备通知监听完成入账，适合自有业务验证与小流量场景，请自行评估合规与风控。

App 离线会怎样？

设备心跳丢失后平台会标记离线并尽量推送告警。离线期间到账无法自动上报，恢复后可在「未匹配到账」人工处理。

同金额并发如何处理？

支持金额微调与多码槽位，降低撞码概率。仍冲突时进入未匹配队列，可在控制台补单绑定。

如何对接自己的系统？

登录商户控制台查看「开发者 API」：使用 Access Key 与签名头创建订单，以返回的 pay_url / 二维码收款，并处理异步回调。
